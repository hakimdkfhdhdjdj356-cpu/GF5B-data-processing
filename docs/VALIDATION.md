# 验证状态与证据边界

本文档刻意区分「本仓库能独立复现的验证」与「作者在本机、用自备数据做过但本仓库不含其数据的实跑」。后者不能由克隆本仓库的人复现，因此不作为本仓库的验收结论。

## A. 本仓库可复现（CI 持续执行）

| 项目 | 内容 | 证据 |
| --- | --- | --- |
| 纯单元测试 | IARR 数值与确定性、坏波段与旧因子拒绝、后端注册与契约、6SV 反演公式与 SRF 采样、坡度/坡向/光照/SCS+C 几何、配置校验 | `tests/`、`.github/workflows/ci.yml` |
| golden 回归 | 需要自备 L1 场景数据；未配置时整类 `skip`，**不伪造通过** | `tests/test_golden.py` |
| 字节编译 | `ahsi/` 与 `scripts/` 全部模块 | CI |
| 元数据检查 | 配置可解析、默认配置无本机路径、仓库未跟踪栅格数据 | CI |

CI 在 Python 3.10 / 3.11 / 3.12、Ubuntu 上运行；`rasterio`/`fiona` 依赖官方 wheel 内置的 GDAL。

## B. 作者本机曾完成、但本仓库不含数据

以下实跑使用的是作者自备的 GF-5B AHSI L1 产品、DEM 与参考影像，**这些数据与产物没有也不会包含在仓库中**。列出它们只为说明代码路径确实被执行过，不构成对本仓库输出精度的保证：

- 无 ENVI 依赖的 IARR 端到端 SMOKE（`radiance → IARR 因子 → 相对反射率 → QC`）。
- `sixs_lut` 后端的完整 LUT 生成与 float32 反射率反演（6S V1.1 + Py6S，2.5 nm 高斯 SRF，三档 AOT/水汽假设情景）。
- SCS+C 地形光照校正（逐波段 C 回归，低光照 QA）。
- 四阶段同点光谱链对比（DN / 辐亮度 / 大气校正 / 地形校正）。
- 与既有人工处理成果的辐亮度抽样像元回归比对、golden 元数据回归。

作者本地在有数据环境下全量单元测试为 **49 项通过**；无数据的 CI 环境中 golden 类自动跳过，其余执行。

## D. 使用时的最低要求

任何基于本仓库产出的结论，都应同时说明：所用后端、产品等级、大气参数来源、是否做过地形校正、以及上表中对应的未验证事项。QC = PASS 只表示工程检查通过，**不等于**物理量精度认证。
